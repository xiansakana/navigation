按 respect 升序自动连续分批检查 Leader，networth 历史也自动续批，跨 Torn 日期自动刷新当前帮派继续，无需手动启动。选择最近一次满足降幅、且之后没有任何日快照回到下跌前高点的日期，计算 A、B、C；仅 C≥A 且 A−B 在配置范围内才命中。

API 请求间隔可设 1–60 秒，默认 2 秒。同一 Torn 账号与帮派摧毁监控共用额度，同时运行时采用较慢的设置。仅修改 API 间隔会保留列表、结果及历史缓存，保存后点击继续扫描。长扫描跨日时保留已完成结果，A/B/C 以各行显示的核验基准日为准。

A=下跌日至今天数，B=Leader 最后活动日至今天数，C=当前帮派中的天数。A、B 按 Torn UTC 日期计算。金额直接输入整数，例如 1000000000 表示减少 10 亿 Torn $。单日金额=前一日净资产−当日净资产；距高点金额=此前最高净资产−当日净资产。再次回到或超过该高点的旧下跌会被排除。选择有限窗口时只确认窗口内高点。

从最近日期倒序追溯，利用最后更新时间跳过未变化区间；先用身份条件排除不可能命中的帮派。多个已授权账号的 Key 分担请求；同一 Torn 账号的多个 Key 与帮派摧毁监控共用配置的账号请求额度，不会叠加提速。返回时间戳为该数值最后更新时间，早于查询日属正常，按截至查询日的数值使用；重复时间戳不算新的下跌。缺失、未来更新、时间和值矛盾或 Leader 变更标为“待确认”。修改筛选条件会重置当前列表和结果，仅改 API 间隔则保留；历史缓存始终保留。此功能不发送通知。
