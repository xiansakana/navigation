# navigation

ECS 服务导航与自托管应用（portal 统一入口 :80）。

## 目录

| 目录 | 说明 |
|------|------|
| `portal/` | 服务导航、登录、反代 |
| `qq-bot/` | 通知管理服务（QQ / 邮件，QQ 通过 NapCat） |
| `torn-toolbox-desktop/` | Torn 压价助手 + 公司监听（独立进程） |
| `stock-manage/` | 美股持仓管理（:5000，服务端持久化） |
| `qqq-dip/` | QQQ 抄底监控与 QQ 提醒（:5001，独立库） |
| `alist/` | AList 网盘聚合（本机 :5244 → Portal `/alist/`） |
| `scripts/` | ECS 部署与运维脚本 |

## 首页博客

博客使用一个可视化编辑框，工具栏格式与 Markdown 输入规则兼容：输入 `# `、`- `、`> `、`**文字**` 等自动排版，也可直接粘贴整段 Markdown（含代码块、表格）。已有 Markdown 文章打开后可继续以富文本编辑。发布框显示时自动请求浏览器定位授权，获取成功后随文章保存坐标；拒绝或失败时仍可发布。可移除位置或重新定位，编辑已有文章时保留原来的位置。图片在待发布、编辑和已发布状态均可点击页内预览。

支持富文本格式（加粗、斜体、下划线、删除线、标题、列表、引用和链接）以及文章标签。输入标签后按回车或点击「添加标签」，已有标签可从输入建议中复用；点击标签可筛选动态。每篇最多 20 个标签，每个最多 30 字。标签随文章保存在共享 SQLite 的 `blog_post_tags` 表中，编辑与删除遵循文章权限。富文本由服务端按允许列表清理后保存，旧纯文本文章无需转换即可继续显示与编辑。粘贴 Markdown 会自动转换成可继续编辑的格式。

首页博客以时间线展示文字、图片和视频动态。管理员在「权限管理 → 角色」给角色分配「首页博客」下的查看、发布或管理权限；发布权限可编辑和删除自己的文章，管理权限可编辑和删除全部文章。游客默认没有博客权限，可以按需单独授予查看权限。文章及媒体 URL 和归属信息保存在共享 SQLite 的 `blog_posts`、`blog_media` 表中，按 Portal 用户 ID 记录作者。图片在浏览器统一转换为 JPG，通过 Portal 服务端调用 PicList 上传到 B2，不再限制 4 张或原文件 5MB；视频通过 Portal 服务端使用 PicList 的 B2 配置直接上传，支持 MP4、WebM、MOV，单个 50MB 以内。现有 `blog_images` 中的旧图片仍可读取。B2 媒体 URL 为公开链接，获得链接的人可直接访问。

Torn 浏览器用户脚本在独立仓库 [xiansakana-torn-scripts](https://github.com/xiansakana/xiansakana-torn-scripts)。

## 命理模块

登录后从首页「命理」进入 `/mingli/`。模块沿用 Portal 主题与布局，不依赖第三方排盘 API。支持 1901—2099 年公历／农历（含闰月）输入、四柱、十神、藏干、纳音、旬空、八字五行字数、大运、流年与流月，以及个人案例的保存、搜索、编辑、删除、标签和事件笔记。

时间统一输入北京时间（UTC+8），历史夏令时需手动换算。年柱以立春、月柱以十二节的精确时刻划分；日柱可选 00:00／23:00 换日，起运可选传统时辰／分钟折算。晚子时时干沿用 `lunar-javascript` 的子时口径。可选经度与天文均时差修正的真太阳时，仅用于日、时柱；年、月柱与起运保持实际时刻。大运年龄为虚岁，年度表不替代精确交运时刻。五行字数不代表旺衰或喜用神。

历法引擎为 MIT 许可的 [lunar-javascript 1.7.7](https://github.com/6tail/lunar-javascript)。案例与计算快照保存于共享 SQLite 的 `mingli_cases` 表，包含计算版本和排盘口径，按 Portal `userId` 隔离，管理员也不能通过案例 API 读取他人的记录。普通登录成员默认获得个人命理权限（与个人记账相同），游客不可访问。权限目录在「首页 → 命理」下，页面与 API 均校验权限；跨站写入被拒绝。

随 Portal 部署，无新增端口或配置；表在首次使用时自动创建，现有 SQLite 备份覆盖案例数据。验证：在 `portal/` 下执行 `node --test src/*.test.js`（Node 版本需与本地 `better-sqlite3` 二进制一致）。

案例库中的「导入问真案例」接受 `navigation-wenzhen-v1` JSON 迁移文件（最大 2MB），先预览并逐条核对四柱，再确认写入。迁移文件由用户授权读取已登录问真账号的案例列表、分组和各案例笔记后生成；不是问真官方导出格式。原站性别 1／2 转为本站男／女，保留原始公历、农历、真太阳时、分组、星标、笔记及四柱来源快照。导入的日时柱沿用原站保存的真太阳时，可在排盘规则中停用；修改出生日期／时间会自动停用，年、月柱与交运仍按原始北京时间。

导入按「当前用户＋原站案例 ID」去重，重复导入不覆盖任何已有内容。原始信息存于 `mingli_cases.source_json`，来源快照在后续编辑时保留。无效日期、时辰不详、需特殊时区／夏令时换算、四柱不一致的文件需先人工核对，确认导入会整批拒绝而非部分写入。新增权限为「首页 → 命理 → 案例库 → 导入案例」，确认写入另需案例编辑权限。备份文件含个人出生信息，保存在仓库外，不提交 Git。

## 部署

见 [DEPLOY-ECS.md](./DEPLOY-ECS.md)。

```bash
# 通过 Cursor/VS Code Remote SSH 连接 ECS 后，在服务器上执行
cd /opt/navigation
git status
git add <本次变更的文件>
git commit -m "描述"
git push origin main
revision=$(git rev-parse HEAD)
./scripts/ecs-update.sh --expected-sha "$revision" --only portal
```

`--only` 按实际受影响服务调整。提交前必须确认没有把配置、数据库、日志或运行时文件加入 Git；拉取或校验失败时停止并排查，不改用 SCP。详细流程见 [DEPLOY-ECS.md](./DEPLOY-ECS.md)。
