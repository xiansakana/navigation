# 扫货助手

入口：Torn 工具箱 → 扫货助手，`/torn-toolbox/shopping/`。按Portal用户在SQLite独立保存Keys、监控物品、价格阈值、通知和去重记录。权限为torn-shopping:view/config:edit/control:edit/history:edit/items:view/notify:view/notify:edit/notify:test:edit，由管理员分配。游客不可编辑，不隐式共享。

保存API Key后，通过“选择物品”下拉列表按名称或ID搜索并多选添加，自动填写物品ID和名称、禁止重复选择；既有监控物品和阈值保留。物品目录从官方torn/items获取，每用户缓存24小时，Keys变化后刷新。分别设置市场、巴扎最高购买价（包含边界）；留空关闭对应来源。最多100物品、10 Keys。留空Keys保留原值，不回传密钥。默认完整轮次结束后等30秒，可配置1–3600秒；Torn API按账号共享限速默认2秒，1–60秒可配，与其他监控共用账号额度。巴扎请求在进程内串行至少间隔2秒。不同Key的账号归属校验、失效跳过和限流重试复用监控实现。

市场沿用压价助手的官方market/{itemId}/itemmarket查询，巴扎沿用Weav3r公开marketplace API，不向第三方发送Torn Key。轮询、缓存及第三方覆盖率影响及时性；不保证所有挂单被发现，打开链接确认库存/价格。每次查询最多记录5条最低符合挂单，通知市场链接或卖家巴扎链接，程序不自动购买。

通知统一在“通知管理 → 业务提醒 → 扫货助手”配置，支持QQ群/私聊/@、多目标和Slack，使用通知服务现有认证投递。扫货助手页面仅提供入口链接，不再放通知表单。现有开关和目标保留，无需重新填写。保存后再启动。服务重启后手动启动，关闭网页继续服务器轮询。配置保存停止监控。

同物品/来源/卖家/价格持久去重，降价触发新提醒；相同价格新增库存或同卖家重新上架不会重复提醒。最近200条历史、10000个去重标记，超出窗口的旧价格可能再次提醒。清空历史保留去重。先保存记录再投递；失败显示错误，不自动重发，避免重复通知。没有自动发送测试通知。页面每5秒读取服务器状态。

API资料： https://www.torn.com/swagger/openapi.json ； https://weav3r.dev/api-docs.html 。

权限管理：业务权限位于“首页 → Torn工具箱 → 扫货助手”，分查看、物品选择、保存配置、监控控制、清空记录；通知权限独立位于“首页 → 通知管理 → 业务提醒 → 扫货助手”。API和前端同时校验，仅读权限无法保存、启停、清空或查询未授权的目录。
