# 扫货助手

入口：Torn 工具箱 → 扫货助手，`/torn-toolbox/shopping/`。按Portal用户在SQLite独立保存Keys、监控物品、价格阈值、通知和去重记录。权限为torn-shopping:view/config:edit/control:edit/history:edit/notify:view/notify:edit/notify:test:edit，由管理员分配。游客不可编辑，不隐式共享。

填写物品ID和名称，分别设置市场、巴扎最高购买价（包含边界）；留空关闭对应来源。最多100物品、10 Keys。留空Keys保留原值，不回传密钥。默认完整轮次结束后等30秒，可配置10–3600秒；Torn API按账号共享限速默认2秒，1–60秒可配，与其他监控共用账号额度。巴扎请求在进程内串行至少间隔2秒。不同Key的账号归属校验、失效跳过和限流重试复用监控实现。

市场沿用压价助手的官方market/{itemId}/itemmarket查询，巴扎沿用Weav3r公开marketplace API，不向第三方发送Torn Key。轮询、缓存及第三方覆盖率影响及时性；不保证所有挂单被发现，打开链接确认库存/价格。每次查询最多记录5条最低符合挂单，通知市场链接或卖家巴扎链接，程序不自动购买。

本页QQ通知支持群或私聊及群内@，使用通知服务现有认证投递。保存后再启动。服务重启后手动启动，关闭网页继续服务器轮询。配置保存停止监控。

同物品/来源/卖家/价格持久去重，降价触发新提醒；相同价格新增库存或同卖家重新上架不会重复提醒。最近200条历史、10000个去重标记，超出窗口的旧价格可能再次提醒。清空历史保留去重。先保存记录再投递；失败显示错误，不自动重发，避免重复通知。没有自动发送测试通知。页面每5秒读取服务器状态。

API资料： https://www.torn.com/swagger/openapi.json ； https://weav3r.dev/api-docs.html 。
