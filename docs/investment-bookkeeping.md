# 证券账户与记账账户联动

股票管理 → 账户管理，新建一个指定币种（USD/CNY）的证券资金账户，明确确认当前现金余额，再选择本人名下同币种、未归档、非信用卡的记账账户。多个资金账户的现金按币种自动汇总。首次启用后旧手工现金保留在原用户数据中作快照，不重复叠加；新用户和未配置用户保持原行为。

“理财／海外理财”现有余额可能是旧总资产，不能用其减去新市值推算现金。绑定时保存旧余额作核对，记录绑定及每次现金核对审计。历史交易不自动猜测账户，可在交易编辑中选择，或明确确认将同币种未归属历史批量归入某账户。新交易选择实际账户；同币种仅一个账户时后端允许默认归属，多账户时必须明确选择。导出保留账户ID，导入验证归属；选择账户时替换导入只替换该账户。

## 核算与双向展示

- 股票用户数据仍按 Portal userId 隔离，investment_accounts/audit 同样带 user_id。每个记账账户只能绑定本人一个证券资金账户，不能跨币种或跨用户。
- 现金＝已确认基准现金＋基准后股票买卖、股息、税费等净现金变动＋基准后记账收入、支出、转账等净现金变动。核对时锚定已经存在的流水ID，刷新不会重复计入；基准以前的历史补录不重放扣款。
- 股票买卖本金不自动生成日常收入/支出账单，避免放大消费、收入或重复扣款；股息及费用仍可在股票复盘查看，证券资金明细可穿透区分股票与记账来源。不要在两个模块重复录入同一股息或费用。
- 记账账户的展示余额直接引用现金＋持仓市值，替代原手工余额，不把两者相加。账户计入范围 included 继续由记账控制。资金与持仓事实共用数据库读取，没有双向覆盖余额的同步任务。
- 同证券在不同账户独立FIFO，持仓按账户展示；账户筛选联动持仓、交易、盈亏、复盘和导出。现金字段在启用账户后只读。
- 缺少任一持仓报价时，对应账户及总资产显示待补齐，不用零市值凑合计。展示报价时间/延时状态；账户余额跨页面15秒刷新、切回页面刷新，报价仍以行情供应商与“刷新价格”为准，不承诺券商自动交易同步。
- 绑定账户不能在记账端直接核对总余额、归档、删除或改币种；到证券账户确认现金或先解除绑定。解除时保存当前总资产为一笔记账余额调整，并锚定证券现金，保留审计。
- 无逐日证券估值快照时，记账资产页仅展示当前总资产，不以当前价格伪造历史净值和收益曲线。原普通记账账户的历史反推行为不变。

抄底监控可以读取账户汇总现金；原按计划金额扣款与实际成交可能不一致，启用证券账户后该写入模式明确拒绝，请在股票管理选账户记录实际成交。单独实际买卖桥仍按同币种账户约束，不能跨账户扣款。

## 权限、上线与验证

### 资产页综合投资收益

资产图表提供“资产余额走势／综合投资收益”两个标签，共用日期范围与社保公积金等账户排除选项。综合收益为 CNY 估算金额：可比观测期间净资产变化减去账单净资金流及余额调整；包含证券估值、股息和外币存量汇率影响，已经记为普通收入、支出的项目不重复计入。它是全体计入账户的估值差额，不是券商报表收益或投资收益率，未记录的资金变动仍可能进入差额。

收益只从真实逐日估值快照开始，使用前一可用快照作为零基准、今日使用当前暂估；早期账单反推段、账面与证券估值切换差额不计算收益。少于两个可比较观测点不绘图；日期范围不完整时显示实际覆盖日期。内部转账本金不作外部资金流，跨账户范围转账按对应账户收付金额和账单日历史汇率核算；手续费按账单支出。账户范围、币种、绑定变化、证券现金重新核对、未知归属或缺失汇率时提示无法可靠计算，避免把本金校正记作收益。缺失日不补造收益点，历史快照保持不变。

新增权限 bookkeeping:accounts:returns:view，需同时具备资产查看与趋势分析权限；证券现金不可见时 API 不返回综合收益，浏览器隐藏标签。新默认个人权限包含该项；自定义成员权限策略继续由管理员授权。

### 证券收益的交易与快照分段统计

证券图表以所选范围首日前一日日末归零，保留已实现净收益、浮盈变化和证券总收益的独立显隐。首份有效账户范围内的估值快照之前，仅根据交易统计已实现净收益，总收益与净收益重合；图中明确标注“未计历史浮盈”，不代表真实浮盈为零。不再为这段历史请求过期期权等旧日线，也不会以当前股价倒算过去浮盈。

首份快照的已有持仓浮盈只作为固定基准，之后计入相对基准的浮盈变化，避免切换当天把已有浮盈一次性计入收益。基准按快照实际采集时间以前的成交和快照保存的价格、汇率还原；该基准独立于用户选择的时间范围，不因切换周、月、年或自定义范围改变。历史估值读取原账户快照，未采集日沿用此前已知观测（报价最多七天），今日使用股票模块最新可用报价和当前汇率暂估。没有首份快照时保持仅含已实现收益；快照基准价格或成本不完整时明确提示，不能用零凑基准。

范围前的交易继续还原 FIFO 成本；买入实际金额、卖出收入按各自交易日汇率折算，佣金、股息、税费和其他证券收支保留。各账户、证券、币种独立匹配，未归属旧记录作为独立历史池。该统计不包含历史现金存量汇兑和未记录持仓，与另列的全资产快照收益口径不同。

只读使用当前用户且在范围内的资产快照，不改写原快照、账户余额、成交或账单。证券现金与交易记录权限继续同时校验；日期和账户排除范围改变时，按同一首份快照基准重新计算。已有行情缓存仅保留其公司行为资料用于成本还原，不再触发历史行情回补任务。

公司行为参考包括 [Nasdaq TSLQ 2025-10-21 的 1 并 3 公告](https://www.nasdaqtrader.com/TraderNews.aspx?id=ECA2025-571)。已在成交中以同一时间、同账户的一卖一买记录的份额换算，按原成交先卖后买重放，不重复拆并股。

新增 service:stock-manage:accounts:view/edit 及账户列权限。核对、管理需现金编辑权限；绑定/解绑同时需要记账账户编辑权限；选项读取需记账账户查看权限。所有操作由 Portal 认证用户归属，参数中的 userId 不生效。记账展示证券资产还检查证券现金权限，不能由另一模块绕过现金隐藏。

表结构幂等创建，部署不会自动绑定真实账户、分配历史或填写现金。首次设置由用户核对，不能根据旧理财快照自动猜值。部署 portal、stock-manage、qqq-dip，运行三服务相关测试；测试涵盖陈旧快照、转账手续费、交易修改删除、重复刷新、现金重新核对、FIFO跨账户、跨用户权限、缺失行情、解绑和真实HTTP接口。产品UI使用独立模拟数据验证，禁止将测试账户写入真实账本。
