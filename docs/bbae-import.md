# BBAE 订单导入

股票管理 → 导入交易，选择本人名下的美元证券账户，分别上传 BBAE「股票订单」「期权订单」xlsx。使用合并模式；文件可能仅包含当前筛选或部分日期，不能用它替换账户全部交易。

按成交数量和成交价核算本金，期权乘数为100；买入费用＝总计−本金，卖出费用＝本金−总计。总计与本金矛盾时整批拒绝。无成交数量的挂单、撤单不入账；部分成交订单仅记录累计已成交数量。时间按本示例导出的北京时间转换，不能以服务端本地时区解释。

预览显示数量、本金、总费用及新增/更新/重复跳过。更新必须在核对预览后明确勾选确认；后端独立检查，不依赖隐藏按钮。没有账户或选择他人/非美元账户时拒绝。导入后持仓按账户核算，现金沿用既有现金基准和基准后的流水投影，不将订单总计与手续费重复扣除。

导出没有订单编号，用代码、方向及下单时间（秒）生成来源标识，并以账户区分。同一来源订单重导不会新增；累计成交变化会标记更新，确认后沿用原交易ID。旧手工记录仅在同账户、代码、方向、成交分钟唯一匹配时更新，保留名称与ID；模糊匹配拒绝。手工编辑导入记录后保留来源标识，后续重导仍可识别。文件内同秒同代码同方向订单无法安全区分时拒绝。

限制：无订单编号时，修改代码、方向或下单时间会影响身份匹配；不自动猜测错误代码或其他账户/未归属历史的归属。遇到可能重复的未归属历史会阻止整批导入，需先核对归属。旧手工成交时间允许前后60秒误差（兼容分钟四舍五入），多条候选仍拒绝。导出平均成交价精度以文件为准；本功能不导入股息、税款、出入金或券商余额，也不重置现金基准。历史补录不重放基准之前的现金变动。导入前应先整理未归属历史，核对预览；源文件不含的订单不会被删除。
