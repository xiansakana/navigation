# 东方财富交割单导入

股票管理 → 导入交易，选择本人名下的人民币证券账户，上传东方财富交割单 XLSX，预览后合并导入。资金流水仅用于对账，不作为交易导入来源。券商原始文件不允许替换整个账户。

## 支持范围

- 证券买入、证券卖出：保留证券代码、名称、数量、成交均价和成交金额；总费用为佣金、其他费用、印花税、过户费之和。校验实际资金发生额，买入为负本金减费用，卖出为本金减费用。
- 红利入账、利息归本：分别记为人民币其他收支中的股息、利息，不增加证券数量。
- 配售缴款与新股入账：以股东账号和流水号唯一关联，使用入账证券代码和名称，按缴款日合成为有成本的买入。保留证券入账日期；缴款后至入账前也会显示该笔持仓。缺失唯一关联时不生成零成本持仓，预览提示补充完整交割单。已有不同日期的疑似手工新债买入时阻止导入，先核对历史。
- 报价回购、天天宝本金申赎、银行出入金、台账划转及未知业务：按类别统计未导入原因，不记作利润，不调整理财资产或记账转账。这是当前明确限定的交易导入范围。

现金按交收日期和发生时间（北京时间）入账，原发生日期另存。不会以交割单中的资金余额覆盖证券账户现金基准。现金基准之前的历史导入不重复扣减当前现金；基准之后的证券交易及收益正常计入。由于本功能不导入理财本金和转账，不能用它单独重建整个券商账户现金流水。

## 去重与更新

来源标识取股东账号、交收日期、类别、原证券代码、时间、成交编号与流水号的 SHA-256，不以文件名或行号识别，因此月度与全年重叠导出可去重。证券账户 ID 再参与存储 ID 生成，不跨用户或账户覆盖。

优先匹配来源标识。无来源标识的手工历史按同账户、代码、方向和前后一分钟检查；其他收支还需同类别或同金额。有歧义时整次拒绝；发现可能重复的未归属历史时提示先归属账户。金额、费用等变化需要明确勾选允许更新，匹配后保留原记录 ID 和现金基准关联。

预览是只读操作，显示可导入数量、新增/更新/重复统计、未单独导入的类别原因和警告。导入接口会重新解析、校验，不依赖浏览器传入的预览结果。

## 验证

回归覆盖费用与净现金、日期校验、分红不增持仓、新债成本与售后盈亏、缺失成本、跨文件去重、更新保留 ID、账户币种及用户隔离、重复入库现金不重复扣减。真实全年样例 489 条来源记录生成 205 条交易：195 条买卖、7 条分红/利息、3 条新债买入；3 条证券入账合并，其余 281 条本金/转账不导入。月度样例生成 9 条交易，均与全年导入标识一致。
